# CS348 Final Project - Application Tracker
## Technologies Used
- Frontend: React, Javascript, HTML, CSS
- Backend: Python, Flask, SQLAlchemy, SQLite
## Features
- Add applications
- Edit applications and deleted
- Update application status
- Filters on application date and status
- Statistics on applications
